# Prompt Canva AI: Aset Tema Premium "Sage"
n> Untuk tema Premium baru, pakai `docs/PROMPT-CANVA-TEMA.md`. File ini arsip prompt Sage Garden.

Salin satu kotak, tempel ke Canva AI (Magic Media), generate, lalu download PNG.
Simpan ke folder `aset-mentah/premium-sage/` dengan nama sesuai judul.

**Pelajaran dari percobaan pertama (12 Nov 2026):**
- Kerjakan gambar kertas (nomor 1) di percakapan terpisah. Kalau satu percakapan, Canva ikut melukis bunga di atas kertas.
- Kata kunci yang berhasil: `clipart`, `isolated on a plain pure white background`, `no paper texture`, `white roses with soft grey shading`, `deep sage green`.
- BG Remover tidak wajib. Kalau kelopak putih ikut terhapus, download dengan latar putih saja; latar putih bisa dihilangkan lewat kode (mix-blend-mode multiply) di bagian berlatar terang.
- Link dan screenshot referensi tidak perlu dimasukkan. Screenshot di `aset-mentah/referensi/` hanya dipakai kalau susunan hasil salah, dengan tambahan kalimat: `follow only the layout of the reference image, use different flowers and colors`.
